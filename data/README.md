# Sample seed data — NOT live

`districts_sample.json` contains a handful of real Indian districts with approximate
population figures referenced from public 2011 Census summaries, and a hand-set
`vulnerability_index` (0-1, higher = more exposed infrastructure/terrain risk) that is a
placeholder judgment call, not a sourced statistic. This exists purely so the GIS/impact and
relief modules have something real-shaped to compute against today.

**Before any real demo or submission claim:** replace this with an actual district boundary
+ population + infrastructure dataset — candidates: `data.gov.in`, Census 2011 district
handbooks, Bhuvan (ISRO) geospatial layers, or your state's SDMA open data if published.
